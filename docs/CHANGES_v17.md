- **Fair Value:** KPI 4 ช่อง (+ "ราคา = x เท่าของมูลค่า") · แผนภาพเทียบ DCF / P/E / มูลค่าผสม / ราคา · ความมั่นใจพร้อมเหตุผล · คะแนนย่อยจริงของแต่ละวิธี · Market Expectation · ตารางสมมติฐานพร้อมแหล่งที่มาและข้อจำกัด 4 ข้อของ WACC / P/E

- **Entry Timing:** KPI 4 ช่อง · เกณฑ์ 6 ข้อพร้อมแต้ม · กราฟ 3 ช่อง (ราคา + EMA20/EMA50/MA200 + เส้นแนวต้าน/แนวรับ/Stop Loss มีชื่อและราคา, Volume, MACD) · ปุ่มช่วงเวลาภาษาไทย · ระดับราคาอ้างอิงพร้อม % · เหตุผล 3 ข้อ (✓ / ◐ / ✕)
- **AI Prediction:** สถานะโมเดล · ผลสอบ (ความแม่นยำ, Baseline, ROC-AUC, วันฝึก/ทดสอบ, ผ่าน/ไม่ผ่าน 2 เงื่อนไข) · NO EDGE → ช่องทิศทาง/โอกาส/คะแนนเป็นสีเทา · Forecast เส้นกลางแบนเมื่อไม่ผ่านด่าน · ความสำคัญตัวชี้วัดพร้อมชื่อภาษาไทย

## 5.4 v17.3 — แก้ error ตอน deploy บน Streamlit Cloud (10 ต.ค. 2569)

- **อาการ:** `สร้างฐานข้อมูลอัตโนมัติไม่สำเร็จ: (sqlite3.OperationalError) table stock_financials already exists`
- **สาเหตุ:** มีการสร้างฐานข้อมูลซ้อนกัน 2 รอบพร้อมกัน (เช่น เปิดแอป 2 แท็บ / กดรีเฟรช / มีผู้ใช้ 2 คนระหว่างที่ระบบสร้างฐานข้อมูลครั้งแรก) ทดลองซ้ำในเครื่องด้วยการสั่ง import พร้อมกัน 3 ชุด ได้ error เดียวกันทุกตัวอักษร
- **แก้:**
  - `common.py`: เพิ่ม `_build_lock()` (กุญแจตัวเดียวทุก session) ให้สร้างฐานข้อมูลได้ทีละรอบ และเช็คซ้ำหลังได้กุญแจ · ตั้ง SQLite timeout 60 วินาที
  - `import_data.write_table()`: ลบตารางเดิม (`DROP TABLE IF EXISTS`) ก่อนเขียนทุกตาราง ใช้ทั้งใน `import_data.py` และ `calculate_scores.py`
  - `calculate_scores.py`: เขียนตาราง `cis_summary_scores` เป็นตารางสุดท้าย แอปจึงถือว่าพร้อมก็ต่อเมื่อทุกตารางเขียนเสร็จ · CALC_VERSION v17.3 (สูตรและตัวเลขไม่เปลี่ยน)
  - แนบ `cis_database.db` ที่คำนวณแล้วไปใน zip — บน Cloud แอปเปิดได้ทันทีโดยไม่ต้องสร้างฐานข้อมูลใหม่ · เพิ่ม `.gitignore`
- **ทดสอบ:** เปิดแอปพร้อมกัน 3 session ตอนยังไม่มีฐานข้อมูล → สร้างครั้งเดียว ไม่มี error ทั้ง 3 session

- **ปัญหาเดิม:** ADVANC คะแนน 73 ผ่านเกณฑ์ "พร้อมเข้าซื้อ" (≥ 70 และไม่ต่ำกว่า MA200) แต่บรรทัดสรุปเขียนว่า "รอการยืนยัน" เพราะเงื่อนไขของข้อความดูแค่ว่ามีเกณฑ์ข้อไหนยังไม่ผ่าน ไม่ได้ดูคะแนน
- **แก้:** `calculate_modules/entry_timing.py` เพิ่ม `summary_text()` ใช้เกณฑ์ชุดเดียวกับป้ายสถานะ
  - ต่ำกว่า MA200 → "ควรงดเข้าซื้อ · ราคาต่ำกว่า MA200"
  - คะแนน ≥ 70 → "พร้อมเข้าซื้อ" (ถ้ามีข้อที่ยังไม่ผ่าน ต่อท้าย "· ยังไม่ผ่าน: …")
  - คะแนน 40-69 → "รอสัญญาณ · ยังไม่ผ่าน: …" · ต่ำกว่า 40 → "ควรงดเข้าซื้อ · แนวโน้มและแรงส่งอ่อน"
- ADVANC ตอนนี้: "พร้อมเข้าซื้อ · ยังไม่ผ่าน: ADX ≥ 25, Volume ≥ ค่าเฉลี่ย 20 วัน"
- `CALC_VERSION = "2026-10-10-v17.4"` · `cis_database.db` แก้เฉพาะคอลัมน์ `summary_short` และ `calc_version` (คะแนน อันดับ และคำแนะนำทุกหุ้นเท่า v17.3 ทุกตัว) · `run_tests.py` ตรวจ key `readiness` และ `summary_short` เพิ่ม

## 6. ข้อจำกัดที่ต้องเขียนในเล่ม
1. WACC / Target P/E เป็นค่าเฉลี่ยตลาดเกิดใหม่ ไม่ใช่ของไทยโดยตรง และ WACC อาจสูงกว่าความจริงจากการแปลงสกุลเงิน
2. ROE / ROA ใช้ค่าในไฟล์ของทีมข้อมูล มี 6 แถวที่ ROA เป็นบวกทั้งที่กำไรสุทธิติดลบ (HANA 2025, JMART 2023/2025, THCOM 2024, TRUE 2023/2024) ทีมข้อมูลต้องอธิบายสูตร
3. เกณฑ์ป้าย (50/65/75, 65/50, 70/40, ±10%), น้ำหนัก และตัวคูณคะแนนเป็นค่าที่ทีมกำหนด (มีผลทดสอบความไว) · เส้นความมั่นใจ 25%/50% และ 2 × ATR ผู้ออกแบบกำหนด
4. โมเดล AI ผ่านด่านเพียง 3 จาก 8 หุ้น (HANA, JMART, THCOM) และ 16/80 ครั้งในการทดสอบย้อนหลัง 10 ปี จึงไม่นับในคะแนนรวม (v17.1)
